Settings

Accent color

The color of the selected tab and the Home background. It also tints the whole interface.

Theme

Light or dark. The accent color follows the theme: it tints the surfaces and text of whichever you pick, and the Home background follows it too.

Animated background

Slowly moving color on the Home page. Turn off for a still image.

Sidebar

Move a link up or down to change where it sits in the sidebar.

Search engine

Used by the Home page and the address bar when you type something that isn't a web address.

Use %s where your search words go. For example: https://example.com/?q=%s

Wisp server

paroxysm connects through a wisp server. Pick one yourself, or let paroxysm find the best one that works.

Tab disguise

Changes the title and icon of this browser tab so it looks like another site.

Character masking

Replaces some letters on proxied pages with lookalike Unicode characters. The page looks the same, but the text in the DOM inspector doesn't match. Higher values replace more letters.

0%

It can affect copy and paste, find in page and screen readers. It starts once a page has loaded.

Panic key

Press this key anywhere in paroxysm to leave straight away.

Panic redirect URL

Where the panic key sends you.
