Settings

Accent color

Sets the color of the selected tab and the Home background, and gives the rest of the interface a slight tint.

Theme

Light or dark. Your accent color tints whichever one you pick, including the Home background.

Animated background

Slow moving color on the Home page. Turn it off for a still background.

Sidebar

Choose the order of the sidebar links. They only show when your tabs are in the sidebar layout.

Search engine

Used when you type something on Home or in the address bar that isn't a web address.

Put %s where your search words go, like https://example.com/?q=%s

Wisp server

paroxysm connects through a wisp server. Pick one yourself or let it find one that works.

Tab disguise

Changes this tab's title and icon so it looks like another site.

Character masking

Swaps some letters in paroxysm's own pages (tab titles, menus, Settings) for lookalike characters. They look the same but won't match if someone inspects the text. Higher values swap more letters.

0%

This can break copy and paste, find in page and screen readers on paroxysm's own pages. Websites you visit are never changed.

Panic key

Press this key anywhere in paroxysm to leave right away.

Panic redirect URL

Where the panic key takes you.
